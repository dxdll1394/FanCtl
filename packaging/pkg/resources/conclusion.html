装好了

打开 FanCtl（在「应用程序」里，或 Spotlight 搜 FanCtl）。窗口关掉后它留在菜单栏， 实时显示 62° 2400。

默认是「温度曲线」模式：45°C 以下 1000 rpm，90°C 以上接近满速。 想改成别的，在界面的「控制方式」里切换，或跑：

  • fanctl status — 看转速和温度
  • fanctl set 2200 — 固定 2200 rpm
  • fanctl auto — 交还 macOS 自动控制
  • fanctl doctor — 自检

卸载

先跑 sudo fanctl daemon uninstall（这会把风扇交还系统）， 然后把 FanCtl.app 拖到废纸篓，最后 sudo rm -rf "/Library/Application Support/FanCtl" /Library/Logs/FanCtl。
